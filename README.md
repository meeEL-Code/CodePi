# 🥧 CodePi

> A super simple, English-based web programming language and compiler built to turn plain English into interactive HTML, CSS, and JavaScript.

---

## ✨ Features
- 🗣️ **Human-Readable Syntax**: No complex syntax—write web apps in natural English.
- 🎨 **Automatic Styling**: Instant CSS generation for colors, alignments, and button designs.
- ⚡ **Built-in Interactivity**: Handle JavaScript events effortlessly using simple `when` blocks.
- 🚀 **CLI & Live Dev Server**: Compile and serve locally in one step (`./codepi serve app.cp`).

---

## 🛠️ Quick Start (Termux / Linux)

```bash
# Clone the repository
git clone [https://github.com/meeEL-Code/CodePi.git](https://github.com/meeEL-Code/CodePi.git)
cd CodePi

# Run local live development server
./codepi serve app.cp
